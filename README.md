# Melbicom Data Centers Loop

Seamless minimalist motion graphic loop (`1080x1080`, designed for `~9.6s`, `30fps`) implemented as a single SVG+JS file.

## Run

Open `/Users/pavelkarpovskii/Documents/Codex/melbicom-dc-timeline/index.html` in a browser.

## What it contains

- Scene 1: Timeline milestones from `Jun 2016` to `H1 2026` with snap transitions, pulsing current dot, count morph, and faded ticker.
- Scene 2: Final timeline dot expands to full-screen green circle wipe.
- Scene 3: Brazil dot-matrix reveal, flag icon, and centered headline.
- Seamless loop: reverse circular collapse back to the initial timeline frame.
